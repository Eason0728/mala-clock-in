# 需求：跨店支援時數自動帶入（v1.0，2026-11-05 Eason 九題定案）

## 問題
薪資只讀同仁「自己那家薪酬門市」的打卡核定。同仁到別家店上班的時數，要管理者在「出勤資料 → 跨店支援」逐筆手填；漏填少發、填錯多發。
2026-10 實例（代稱）：A 君金山打卡 62.5H＝手填 62.5H；B 君金山打卡 54.5H／手填 57H、墨竹亭光復打卡 8.5H／手填 12.5H。

## 使用者
人資／會計（薪酬計算模組使用者）。同仁只看結果（薪資單）。

## 定案（Eason 2026-11-05）
| # | 決定 |
|---|---|
| 1B | 每次重新計算自動帶入（不用按鈕） |
| 2A | 用管理系統「同仁名單 → 打卡對照」（DZY 編號 ↔ 各店打卡帳號，confirmed）認人，不用姓名 |
| 3A | 該店已有手填且與打卡不同：不蓋掉，列差異逐筆決定「改成打卡值」或「保留手填」；沒有手填的店直接帶入 |
| 4B | 費率一律帶本人加班費率（計時帶本人時薪） |
| 5 | 2026-11 起只有同品牌算支援；跨品牌由打卡那家店的薪資主檔發薪。央廚、鼎兆元總部跟誰都算同品牌 |
| 6A | 每筆帶入可展開逐日明細（日期、時段、核定時數、核定人） |
| 7B | 只從 2026-11 起；2026-10 以前完全不變（維持手填） |
| 8A | 跨品牌在打卡店建的主檔：計時、時薪＝本人在原店的加班費率；勞健保、退休金、宿舍不扣；全勤、餐費、年終不給 |
| 9A | 跨品牌造成原店正職時數變少 → 照現行規則不足時數倒扣（兩份合計與現在相同） |

## 核心功能
1. 計算 2026-11 以後月份時，自動找出本店同仁在「同組其他店」主管已核定的時數，依店帶進跨店支援。
2. 有手填衝突時列差異、逐筆決定。
3. 跨品牌打卡不帶入原店；打卡店的薪酬計算提醒「這位同仁在本店有打卡、但沒有主檔」。
4. 防重複：同組支援的人若在打卡店也有主檔 → 警告（會被付兩次）。
5. 逐日明細可展開。

## 不做
- 不改任何計薪公式（正職支援併入總時數用加班費率；計時支援×費率；請款＝支援時數×費率）。
- 不帶未核定時數（提醒「N 天未核定」）。已鎖定月份不動。
- 不自動建跨品牌主檔（8A 是建檔規則，由人照做；系統只提醒）。
- 墨竹亭光復店主檔尚未建：那邊的人照舊。

## 已知風險
- 打卡對照沒確認的帳號帶不進來 → 畫面列「對照未確認」提醒人資。
- 同仁查薪：一人兩張薪資單（原店＋跨品牌打卡店）。打卡頁「我的薪資」依打卡連結各看各店；LINE 薪資明細只看光復——開發時查證並回報。
