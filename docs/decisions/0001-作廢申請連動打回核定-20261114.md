# 0004 作廢已核准的申請時，那天的核定一起打回待核定（2026-11-14）

## 背景
朱明哲 11/1 出差單被總監作廢後，「申請單彙整」出現「申請已作廢、核定還在」：
作廢只改申請單狀態，薪資讀的假別紀錄（打卡端 leave 分頁）沒動，薪資會照舊算出差 7 小時。
另外 11/13 的 bind_revoke 只搬工時核定、沒搬假別紀錄，也會留下同樣的孤兒假別列。

## Eason 拍板（照推薦 1A 2A 3A 4A）
1. **A** 作廢時那位同仁那天的核定整筆打回「待核定」：工時核定（approved）→ `approved_revoked`，假別紀錄（leave）→ `leave_revoked`，都留底可復原；主管要重新核定。
2. **A** 四種單（請假、出差、加班、忘打卡）都適用。
3. **A** 那個月薪資已鎖定就不能作廢（營運系統用 payroll_leave_options 的 locked 擋；打卡端沒回 locked＝不知道，照樣作廢，跟人資退回一樣）。
4. **A** 舊資料先只讀列清單（打卡端 `final_orphan_scan`），Eason 看過再指定要清的人日（apply＋keys）。

## 實作要點
- 打卡端 `handleMgrReqVoid_`：先搬核定、搬完才標作廢；搬的時候出錯回 `revoke_failed`，單子不作廢。總部鏡像列（mirror_src）不動。
- 營運系統考勤管理：已核定的那天按作廢，先提示「核定會打回待核定」；作廢後卡片停用送出、給「重新載入這天」（避免照舊卡片送出被 stale_ver 退回，11/14 謝政倫就是這樣以為沒撤成）。
